# Bizora — Findings Register

Severity: **Critical** = data loss/security breach likely · **High** = core workflow blocked or serious risk ·
**Medium** = real defect/gap with workaround · **Low** = quality/maintainability.
Status: **Confirmed** = evidence in code or reproduced · **Suspected** = needs DB/browser verification · **Suggestion** = improvement, not a defect.
Effort: S ≤1 dev-day · M 2–4 dev-days · L 5+ dev-days.
