# Measurements

## What this is
Each customer's saved sizes. Every save creates a dated **revision** — old measurements are never overwritten, so a fitting mistake can always be traced.

## Where to find it
Web: **Measurements**. Mobile: **More**, then **Measurements**.

## Save measurements
1. Choose the customer and a measurement template (for example Shalwar Kameez).
2. Type each measurement in the unit shown. Text fields accept words (for example "loose fit").
3. Add notes for anything unusual, then **Save revision**.

## What happens next
The new revision becomes the latest one. Orders can attach the measurement profile so the tailor works from exactly these numbers.

## Common mistakes
- Editing in your head and saving twice "to be sure". Two revisions are created — harmless, but pick the right one on the order.
- Measuring over thick clothing without noting it. Write it in notes.

## Permission warnings
Viewing needs **measurements:read**; saving needs **measurements:write**. Measuring is often a tailor's job while order-taking is the counter's — roles can separate them.

## Roman Urdu mein
