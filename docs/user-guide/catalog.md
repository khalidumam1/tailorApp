# Catalog and price list

## What this is
Your ready price list: the items you sell again and again, with prices, so orders start from a tap instead of typing.

## Where to find it
Web: **Catalog**. Mobile: **More**, then **Catalog**. Needs the **catalog** module switched on.

## Add an item
1. Choose **Add item**, pick its item type, name and unit (piece, metre…).
2. Set the selling price. Link a stock variant if the item consumes inventory.
3. Save — it becomes selectable on new orders.

## Stop selling an item
Mark it **inactive** instead of deleting. Old orders keep their prices; the item just leaves the pickers.

## Common mistakes
- Changing a price and expecting old orders to change. They never do — an order keeps the price agreed that day.
- Two catalog items with the same name. Add the difference to the name (for example "Suit — premium stitching").

## Permission warnings
Managed by **orders:write** holders; the module itself is switched on by **settings:manage**.
