# Inventory and stock

## What this is
Fabric, buttons, zips and everything you consume: how much came in, what was used, what is left, and what it is worth.

## Where to find it
Web and mobile: **Operations & finance**, then the **Inventory** tab. Needs the **inventory** module.

## Record stock
1. Create the item and its variants (colour/size).
2. Use movements: **Receipt** when stock arrives, **CONSUMPTION** (shown as Consumption) when an order uses it, **Wastage** for damage, **Adjustment** for count corrections (always with the real counted number).
3. A movement that was wrong is **reversed** with a reason — never edited or deleted. Reversing asks for the reason.

## Reorder alerts
Set a reorder point per variant; the alert list shows what to buy before it runs out.

## Common mistakes
- Typing consumption guesses. Count what the order actually used; small daily truth beats a monthly surprise.
- Negative stock is blocked on purpose. Record the receipt first, then the consumption.

## Permission warnings
Viewing needs **inventory:read**; movements need **inventory:write**.

## Roman Urdu mein
Stock ki har harkat likhein: aamad (Receipt), istemal (Consumption), zaya (Wastage). Ghalat entry delete nahi hoti — wajah likh kar **reverse** karein. Stock minus mein nahi ja sakta; pehle aamad darj karein.
