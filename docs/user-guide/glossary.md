# Glossary — words we use

- **Alteration** — a fitting fix after delivery (shorten, loosen…). Tracked until marked done.
- **Archive** — hide something without deleting it. Archived customers, orders and businesses keep all history and can be restored.
- **Balance / outstanding** — what the customer still owes on an order: total minus net paid.
- **Cashbook** — the daily cash/bank day book.
- **Catalog** — your reusable price list.
- **Consent** — the customer's permission to receive WhatsApp messages.
- **Custom field** — an extra box you added (fabric type, neck size…).
- **Idempotency** — saving twice with the same save-key creates one record, not two. Protects you on flaky connections.
- **Invoice** — the order's printable bill: items, total, payments, balance.
- **Journal** — the double-entry accounting record behind a transaction.
- **Membership** — one person's access to one business, with one role.
- **Module** — a switchable feature area (Inventory, Cashbook…). Owners switch modules in Business settings.
- **Platform** — the team that runs the whole system (not a single shop).
- **Receipt** — proof of one payment.
- **Restore** — bring an archived record back to normal lists.
- **Reversal** — the correction entry that undoes a posted payment. Payments are never edited or deleted.
- **Revision** — one saved version of measurements. New saves add revisions; old ones stay.
- **Role** — a named set of permissions (Counter, Tailor, Manager…).
- **Stage** — a step an order passes through (Cutting, Stitching, Ready…).
- **Tenant** — one business's private data area. Tenants can never see each other's records.
- **Trial / grace period** — free starting period, and the extra days after a period ends before writes pause.

## Roman Urdu mein
Mushkil alfaaz ki sada tareefain upar di gayi hain. Sab se aham: **Archive** matlab chhupana (delete nahi), **Reversal** matlab ghalat payment ki durustgi (purani entry rehti hai), aur **Stage** matlab order ka marhala.
