## Industry cut-down copy

Use the platform headline, swap the hook line. The brand stays Bizora.

| Trade | Hook line | Stage proof |
| --- | --- | --- |
| Auto Workshop | Every vehicle, every job card, every rupee — in one workspace. | Inspection → Estimate → Approved → Repair → Quality check → Ready → Completed |
| Furniture | From design to delivery, every order on one board. | New → Design → Material confirmation → Production → Finishing → Ready → Completed |
| Printing | Every print job, spec and stage, tracked. | New → Design → Production → Finishing → Ready → Completed |
| Carpenter | Jobs, materials and dimensions in one place. | New → Design → Material confirmation → Production → Finishing → Ready → Completed |

Always close with: *Auto Workshop is one of the templates configured on Bizora —
the same platform runs every trade.*

## What not to write

- "The best tailor software" — Bizora is not a tailor app.
- "Integrates with X" — no integrations exist yet.
- "Automated WhatsApp updates" — templates exist; live delivery is not
  production-verified.
- Any number about customers, uptime or savings.
- Any price that has not been agreed.
